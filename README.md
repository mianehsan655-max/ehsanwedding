# Ehsan Ali Weds Nadia Asghar — Luxury Royal Wedding Invitation Website

A bespoke White & 24K Gold interactive digital wedding invitation built in **React.js + Tailwind CSS + Vite**.

## ✨ Key Features

1. **Interactive Sealed Royal Gatefold Invitation**:
   - Opens on a 3D French-gatefold ivory-and-gold invitation card sealed with an embossed `E & N` 24K gold wax emblem, floral filigree corners, and animated golden love birds.
   - Displays the personalized guest's name and family badge directly on the sealed cover.
2. **Sacred Quranic Nikkah Recitation & Arabic Calligraphy**:
   - Clicking **"Open Invitation & Recite Quran"** swings open the 3D gatefold doors and immediately recites **Bismillah-ir-Rahman-ir-Rahim** followed by **Surah Ar-Rum (30:21)** (*The Sacred Ayah of Nikkah*) and **Surah An-Naba (78:8)** by Sheikh Mishary Rashid Alafasy.
   - Features illuminated Arabic calligraphy (`Amiri` / `Scheherazade New`), transliteration, English translation, Urdu translation, and the Prophetic Nikkah Dua.
3. **Bride & Groom Royal Lineage & Portrait Arch**:
   - **Groom**: **Ehsan Ali** (`S/O Mian Muhammad Anwar`)
   - **Bride**: **Nadia Asghar** (`D/O Mian Muhammad Asghar`)
   - Framed inside an ornate Mughal & Botanical Gold Arch with animated golden love birds and a live countdown to December 19, 2026.
   - Includes a high-resolution royal white-and-gold couple portrait (`/couple-portrait.png`) plus online PNG wedding couple resources selectable from **Host Mode**.
4. **Complete 3-Day Events Itinerary**:
   - **Mehndi Ceremony**: `07:00 PM` on `19 December 2026` at `Chak No. 655 GB Parkash Nagar, Tehsil Jaranwala, District Faisalabad`.
   - **Barat Procession & Reception**: Departing from `Chak No. 655 GB Parkash Nagar` at `05:00 PM` on `20 December 2026` and arriving at `Sardar Marquee, Faisalabad Road, Jaranwala, Punjab, Pakistan` at `06:00 PM` on `20 December 2026`.
   - **Waleema Ceremony**: `02:00 PM` on `21 December 2026` at `Shahzeb Marquee, Mandi Buchiana, Tehsil Jaranwala, District Faisalabad`.
5. **Host Mode & Personalized Guest Link Studio**:
   - Click **"Host Mode"** in the top-right header (or visit `?mode=host`) to add guests, select their honorific title (`Respected`, `Honorable`, `Mian`, `Chaudhry`, etc.), choose which events they are invited to, and generate a private shareable link or send directly via **WhatsApp**.

## 🚀 Running Locally

```bash
npm install
npm run dev
```
